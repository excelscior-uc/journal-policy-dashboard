# Dashboard Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the journal policy dashboard as a Vite + React SPA with a landing home screen, per-field pages, Recharts replacing Plotly, and 3-layer lazy loading — deployable to GitHub Pages.

**Architecture:** Split-page SPA using React Router v6 (HashRouter). Chart data extracted from the legacy monolith into per-field JSON files served from `public/data/`. Charts render only when scrolled into view via IntersectionObserver.

**Tech Stack:** Vite 5, React 18, React Router v6, Recharts, Vitest, GitHub Actions

## Plot ID Reference

The legacy `index.html` contains these plot ID patterns (critical for extraction):

| Pattern | Count | Description |
|---------|-------|-------------|
| `plot_about_agg_{all\|pol\|npo}` | 3 | Global agg (about panel) |
| `plot_global_agg_{global\|pol\|npo}` | 3 | Global agg (global panel) |
| `plot_fagg_{FIELD}_{all\|pol\|npo}` | 36 | Per-field agg (field panel) |
| `plot_gfagg_{FIELD}_{all\|pol\|npo}` | 36 | Per-field agg (global panel) |
| `jplot_{FIELD}_{JOURNAL_ABBREV}` | ~257 | Per-journal charts |

`FIELD` values: `Cardiac_and_Cardiovascular_Systems`, `Clinical_Neurology`, `Endocrinology_and_Metabolism`, `Genetics_and_Heredity`, `Immunology`, `Neurosciences`, `Oncology`, `Orthopedics`, `Pharmacology_and_Pharmacy`, `Physiology`, `Rheumatology`, `Urology_and_Nephrology`

### Task 3: Data extraction script

**Files:**
- Create: `scripts/extract-data.js`
- Create: `tests/extract-data.test.js`
- Output: `public/data/*.json`

The script reads `scripts/source.html`, executes each chart IIFE using Node's `vm` module with a mocked `Plotly`, then converts captured Plotly traces to Recharts-compatible JSON.

**Plotly trace → Recharts conversion rules:**
- Traces with `legendgroup === 'policy_vlines'`: extract `x[0]` as year, parse label from `hovertemplate`
- All other data traces: zip `x[]` and `y[]` into flat chartData object `{year, value}` keyed by series name
- Series key mapping: `"% only bar"` → `pct_only_bar`, `"% bar and informative"` → `pct_bar_informative`, `"% only informative"` → `pct_only_informative`, `"% eligible articles"` → `pct_eligible`

**Field slug mapping:**
```
Cardiac_and_Cardiovascular_Systems → cardiac
Clinical_Neurology                  → clinical-neurology
Endocrinology_and_Metabolism        → endocrinology
Genetics_and_Heredity               → genetics
Immunology                          → immunology
Neurosciences                       → neurosciences
Oncology                            → oncology
Orthopedics                         → orthopedics
Pharmacology_and_Pharmacy           → pharmacology
Physiology                          → physiology
Rheumatology                        → rheumatology
Urology_and_Nephrology              → urology
```

```js
// scripts/extract-data.js
import { readFileSync, writeFileSync, mkdirSync } from 'fs'
import { createContext, runInContext } from 'vm'
import { join, dirname } from 'path'
import { fileURLToPath } from 'url'

const __dirname = dirname(fileURLToPath(import.meta.url))

export const seriesKeyMap = {
  '% only bar': 'pct_only_bar',
  '% bar and informative': 'pct_bar_informative',
  '% only informative': 'pct_only_informative',
  '% eligible articles': 'pct_eligible',
}

export function tracesToChartData(traces) {
  const dataTraces = traces.filter(t => t.legendgroup !== 'policy_vlines' && seriesKeyMap[t.legendgroup])
  if (!dataTraces.length) return []

  const years = dataTraces[0].x
  return years.map((year, i) => {
    const point = { year }
    for (const trace of dataTraces) {
      const key = seriesKeyMap[trace.legendgroup]
      if (key) point[key] = trace.y[i] ?? null
    }
    return point
  })
}

export function tracesToPolicyLines(traces) {
  const seen = new Set()
  return traces
    .filter(t => t.legendgroup === 'policy_vlines')
    .reduce((acc, t) => {
      const year = t.x[0]
      if (seen.has(year)) return acc
      seen.add(year)
      const match = t.hovertemplate?.match(/(\d+% of journals[^<]*)/)
      acc.push({ year, label: match ? match[1] : '' })
      return acc
    }, [])
}

const FIELD_SLUG_MAP = {
  Cardiac_and_Cardiovascular_Systems: 'cardiac',
  Clinical_Neurology: 'clinical-neurology',
  Endocrinology_and_Metabolism: 'endocrinology',
  Genetics_and_Heredity: 'genetics',
  Immunology: 'immunology',
  Neurosciences: 'neurosciences',
  Oncology: 'oncology',
  Orthopedics: 'orthopedics',
  Pharmacology_and_Pharmacy: 'pharmacology',
  Physiology: 'physiology',
  Rheumatology: 'rheumatology',
  Urology_and_Nephrology: 'urology',
}

const FIELD_DISPLAY_MAP = {
  cardiac: 'Cardiac & Cardiovascular Systems',
  'clinical-neurology': 'Clinical Neurology',
  endocrinology: 'Endocrinology & Metabolism',
  genetics: 'Genetics & Heredity',
  immunology: 'Immunology',
  neurosciences: 'Neurosciences',
  oncology: 'Oncology',
  orthopedics: 'Orthopedics',
  pharmacology: 'Pharmacology & Pharmacy',
  physiology: 'Physiology',
  rheumatology: 'Rheumatology',
  urology: 'Urology & Nephrology',
}

function extractPlots(html) {
  const captured = {}
  const scriptRegex = /<script>([\s\S]*?)<\/script>/g
  let match
  while ((match = scriptRegex.exec(html)) !== null) {
    const code = match[1]
    if (!code.includes('Plotly.newPlot')) continue
    try {
      const ctx = createContext({
        Plotly: { newPlot: (id, data, layout) => { captured[id] = { data, layout } } },
      })
      runInContext(code, ctx)
    } catch (_) { /* skip non-chart blocks */ }
  }
  return captured
}

function buildFieldJson(slug, fieldKey, plots) {
  const agg = (suffix) => {
    const key = `plot_fagg_${fieldKey}_${suffix}`
    const p = plots[key]
    if (!p) return null
    return { chartData: tracesToChartData(p.data), policyLines: tracesToPolicyLines(p.data) }
  }

  const journalPrefix = `jplot_${fieldKey}_`
  const journalKeys = Object.keys(plots).filter(k => k.startsWith(journalPrefix))

  const journals = journalKeys.map(k => {
    const name = k.replace(journalPrefix, '').replace(/_/g, ' ')
    const p = plots[k]
    const policyLines = tracesToPolicyLines(p.data)
    return {
      id: k.replace(journalPrefix, '').toLowerCase(),
      name,
      hasPolicy: policyLines.length > 0,
      policyYear: policyLines[0]?.year ?? null,
      chartData: tracesToChartData(p.data),
      policyLines,
    }
  })

  return {
    field: FIELD_DISPLAY_MAP[slug],
    slug,
    aggAll: agg('all'),
    aggPolicy: agg('pol'),
    aggNoPolicy: agg('npo'),
    journals,
  }
}

function buildAllFieldsJson(plots) {
  const p = plots['plot_global_agg_global']
  if (!p) return null
  return {
    field: 'All Research Fields',
    slug: 'all-fields',
    aggAll: { chartData: tracesToChartData(p.data), policyLines: tracesToPolicyLines(p.data) },
    aggPolicy: plots['plot_global_agg_pol']
      ? { chartData: tracesToChartData(plots['plot_global_agg_pol'].data), policyLines: tracesToPolicyLines(plots['plot_global_agg_pol'].data) }
      : null,
    aggNoPolicy: plots['plot_global_agg_npo']
      ? { chartData: tracesToChartData(plots['plot_global_agg_npo'].data), policyLines: tracesToPolicyLines(plots['plot_global_agg_npo'].data) }
      : null,
    journals: [],
  }
}

// Only run main when executed directly (not when imported for tests)
if (process.argv[1] && process.argv[1].endsWith('extract-data.js')) {
  const sourceHtml = readFileSync(join(__dirname, 'source.html'), 'utf8')
  const plots = extractPlots(sourceHtml)
  const outDir = join(__dirname, '../public/data')
  mkdirSync(outDir, { recursive: true })

  for (const [fieldKey, slug] of Object.entries(FIELD_SLUG_MAP)) {
    const json = buildFieldJson(slug, fieldKey, plots)
    writeFileSync(join(outDir, `${slug}.json`), JSON.stringify(json, null, 2))
    console.log(`✓ ${slug}.json`)
  }

  const allFields = buildAllFieldsJson(plots)
  writeFileSync(join(outDir, 'all-fields.json'), JSON.stringify(allFields, null, 2))
  console.log('✓ all-fields.json')
}
```

```js
import { useState, useEffect } from 'react'

export function useVisible(ref, options = { threshold: 0.1 }) {
  const [visible, setVisible] = useState(false)

  useEffect(() => {
    if (!ref.current || visible) return
    const obs = new IntersectionObserver(([entry]) => {
      if (entry.isIntersecting) {
        setVisible(true)
        obs.disconnect()
      }
    }, options)
    obs.observe(ref.current)
    return () => obs.disconnect()
  }, [ref, visible, options])

  return visible
}
```

```jsx
        <div className="field-header">
          <div className="field-header__icon">{field.icon}</div>
          <h2>{field.name}</h2>
        </div>
      )}

      {/* filter bar */}
      <FilterBar
        visibleSeries={visibleSeries}
        onToggleSeries={toggleSeries}
        policyFilter={policyFilter}
        onPolicyFilter={setPolicyFilter}
      />

      {/* main layout */}
      <div className="field-layout">
        {data && (
          <JournalSidebar
            journals={filteredJournals}
            selectedId={selectedJournal}
            onSelect={setSelectedJournal}
          />
        )}

        <div className="chart-area">
          {!data && (
            <div style={{ display: 'flex', flexDirection: 'column', gap: 12 }}>
              {[1, 2, 3, 4].map(i => (
                <div key={i} className="chart-card">
                  <div className="chart-card__header"><span>Loading…</span></div>
                  <div className="chart-card__body chart-card__body--agg">
                    <div className="chart-card__skeleton" />
                  </div>
                </div>
              ))}
            </div>
          )}

          {data && selectedJournal === '__agg__' && (
            <>
              <div className="chart-section-title">Aggregated Trend</div>
              <div className="chart-grid chart-grid--full">
                {aggData && (
                  <ChartCard
                    title={`${field?.name ?? slug} — All Journals`}
                    chartData={aggData.chartData}
                    policyLines={aggData.policyLines}
                    visibleSeries={visibleSeries}
                    tall
                  />
                )}
              </div>

              <div className="chart-section-title">Per-Journal Charts</div>
              <div className="chart-grid">
                {filteredJournals.map(j => (
                  <ChartCard
                    key={j.id}
                    title={j.name}
                    meta={j.hasPolicy ? `Policy ${j.policyYear}` : 'No policy'}
                    chartData={j.chartData}
                    policyLines={j.policyLines}
                    visibleSeries={visibleSeries}
                  />
                ))}
              </div>
            </>
          )}

          {data && activeJournal && (
            <>
              <div className="chart-section-title">
                {activeJournal.name}
                {activeJournal.hasPolicy && (
                  <span className="policy-badge">Policy {activeJournal.policyYear}</span>
                )}
              </div>
              <div className="chart-grid chart-grid--full">
                <ChartCard
                  title={activeJournal.name}
                  chartData={activeJournal.chartData}
                  policyLines={activeJournal.policyLines}
                  visibleSeries={visibleSeries}
                  tall
                />
              </div>
            </>
          )}
        </div>
      </div>
    </>
  )
}
```

```yaml
name: Deploy to GitHub Pages

      - name: Checkout

      - name: Setup Node

        with:

          cache: npm

      - name: Install dependencies
        run: npm ci

      - name: Build
        run: npm run build

      - name: Upload Pages artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: ./dist

  deploy:
    needs: build-and-deploy
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```
